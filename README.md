# Retail Sales Performance Analysis

## 🛒 Retail Sales Analysis

## 📌 Overview
This project analyzes retail sales data to uncover trends, patterns, and business insights using Python, Pandas, and data visualization techniques.

## 🎯 Objectives
- Analyze sales and profit trends over time
- Identify top-performing products and categories
- Evaluate the impact of discounts on profitability
- Provide actionable business recommendations

## 🛠 Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Insights
- Sales increased consistently from 2011 to 2014
- Profit growth follows sales trends but is affected by discounting
- Discounts negatively impact profitability
- Certain regions dominate sales performance

## 💡 Business Recommendations
1. Optimize discount strategies to avoid reducing profit margins.

2. Focus marketing efforts on high-performing products.

3. Invest more resources in top-performing regions.

4. Improve performance in underperforming regions.

5. Consider pricing strategy optimization instead of relying heavily on discounts.
